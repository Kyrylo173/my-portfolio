My personal portfolio website designed to showcase my key projects, technical background, and engineering capabilities. Built with a focus on clean design, performance, and responsive layout across all display sizes.

---

## ✨ Features

* **Project Showcase Gallery:** Curated collection of my largest full-stack applications and projects with live demos.
* **Modern & Clean UI:** Aesthetic, minimalist interface built for high readability and fast loading times.
* **Fully Responsive:** Smooth layout adaptation across all devices (Mobile, Tablet, Desktop).
* **Direct Contact:** Quick links to get in touch for freelance contracts, full-time opportunities, or tech collaboration.
